- 전체 테스트 실행 시 각 파일들은 병렬적으로 실행된다
- 각 파일 내의 테스트들은 순차적으로 실행된다.

테스트 수행 시 workers = execution (실제 수행되는 프로세스들 수)

94.
- 기본적으로 playwright는 parallel하게 수행됨
- 단 worker를 1로 설정하면 sequence하게 수행시킬 수 있다.

95. 
- 아래 코드를 넣으면 parallel 수행됨.
- test.describe.configure({mode:'parallel'});
- 각 테스트가 일련의 이어지는 테스트일 경우(독립적이지 않을 경우)에는 serial로 수행(앞의 테스트에서 fail이 나면 뒤의 테스트를 수행하지 않음)
- default는 각 테스트 실패 여부와 상관없이 독립적으로 수행.
- default : 독립적, serial : 일련(직렬), parallel : 병렬
